2 P0 — Post a job → live

Employer fills the form on /post.html (or improved /post). Within minutes: card on the board, /jobs/{id} page, Apply hits applyUrl. Founding free. No “we’ll review and email you” as the only path.

Primary recommendation

LayerChoice
HostVercel (or similar) + custom domain
AppNext.js — keep hubs; SSR/ISR job pages
DataSupabase (Postgres) jobs table
WritePublic POST /api/jobs + honeypot + rate limit
PublishAuto-live for founding free; admin unpublish stub
SuccessRedirect to live job URL — “Your job is live”
LaterStripe for featured/paid — do not block P0

Alternative

Stay on GitHub Pages: form → serverless function → commit jobs.json + jobs/*.html + sitemap via GitHub token → Pages rebuild. Slower and riskier; acceptable only if Claude documents tradeoffs and still meets acceptance tests.

Acceptance tests

  • Submit test job via UI → appears on homepage list
  • Job detail URL returns 200 with real content
  • Apply button hits submitted applyUrl
  • Sitemap (or equivalent) includes the new job
  • Empty fields / filled honeypot rejected

Copy on post + pricing must say jobs go live immediately (founding free), not review-only email.

3 30-day calendar

Week 1 Technical + measurement

  • Enforce HTTPS when cert ready (or fix via Vercel cutover)
  • Google Search Console + Bing Webmaster + GA4 or Plausible
  • Organization + WebSite + JobPosting JSON-LD; BreadcrumbList
  • Canonical + OG/Twitter on money pages; brand og:image
  • llms.txt + optional FAQ hub stub for AEO
  • Fix thin / inconsistent title and meta

Week 2 Deepen money pages (sourced — no fake stats)

  • salaries.html — PA pay structure; cite DOI/BLS/industry where real
  • become-a-public-adjuster.html — license path + state DOI links
  • locations/fl.html, tx.html, ca.html — licensing notes + links to live jobs
  • remote.html + roles.html depth
  • FAQ: what is a PA; PA vs independent; how PA firms hire — answer-first H2s (40–80 words), then detail

Week 3 Inventory + distribution

  • Post→live working; recruit 10–20 real listings
  • Companies page auto from live jobs
  • Soft outreach: FAPIA/NAPIA-adjacent + LinkedIn PA groups (Josh voice; templates in build spec)
  • Internal linking pass: hubs → jobs

Week 4 AEO polish + iteration

  • Expand FAQ + statistics with honest methodology
  • Add “last updated” dates on guides
  • Submit sitemap; fix GSC coverage issues
  • Optional: job alerts confirmation page SEO
  • Measure impressions, queries, AI citations if observable
